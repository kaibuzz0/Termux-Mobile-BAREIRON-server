⚙ Built Different

Why the binary stays ~227 KB.

No Dimensions

No Nether or End. Keeps the world generator and protocol surface small.

Simple NPC Movement

No full entity pathfinding. NPCs use simple follow logic.

Integer Inventory

Weapons, ammo, and materials are tracked as integers rather than a full item system.

Static World

No block physics, redstone, or fluid flow. The world is static and cheap to serve.

⚠ Network Warning

No authentication. No encryption.

This is an open server designed for trusted LAN or private network play. Do not expose it directly to the public internet without appropriate network protections.

$git clone https://github.com/kaibuzz0/Termux-Mobile-BAREIRON-server.git

README documents Windows under MSYS2 only. build.sh includes MINGW64 linker flags.
